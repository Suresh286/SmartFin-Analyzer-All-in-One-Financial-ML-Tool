# 🚀 SmartFin Analyzer – All-in-One Financial ML Tool 💹

Welcome to **SmartFin Analyzer**, a modern, interactive web app built with **Streamlit**, designed to empower users with essential financial machine learning tools — from price prediction to investor segmentation — all in one seamless experience.

---

## 🔍 Features

### ✅ **Stock Price Prediction**
- Use **Linear Regression** to forecast future stock prices.
- Input your own data or fetch from **yfinance** or **Finnhub**.
- Visualize results with **interactive Plotly charts**.

### 📊 **Stock Movement Classification**
- Apply **Logistic Regression** on technical indicators like RSI, MACD, SMA.
- Understand the probability of upward/downward movements.

### 🧠 **Investor Segmentation**
- Perform **K-Means Clustering** to categorize investors based on behavior.
- Explore in **2D and 3D visualizations** using PCA and t-SNE.
